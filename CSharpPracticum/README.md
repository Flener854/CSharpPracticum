# CSharpPracticum

Репозиторий с решениями практических заданий по C#. Включает в себя работу с LINQ, асинхронностью, коллекциями, Git и базовыми принципами ООП.

## Инструкция по запуску

1. **Требования:**
   * Установленный [.NET SDK](https://dotnet.microsoft.com/download) (версия 8.0 или выше).
   * Любая IDE (Visual Studio 2026, JetBrains Rider, VS Code).
   * Git.

2. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/ваш-профиль/CSharpPracticum.git
   cd CSharpPracticum

3. **Запуск:**
   * Через терминал:
	 dotnet run --project ИмяПроекта
   *Через Visual Studio / Rider: 
     откройте файл решения (.sln), выберите нужный проект (например, Task42_CancellationToken) и нажмите F5.

## Заметки по уровням

### Уровень 1: Базовый синтаксис, массивы и Git-основы (Задания 1–15)
* **Что было сложно:** Разобраться с алгоритмами сортировки (пузырьком и вставками) без встроенных методов. Понять, как правильно разрешать конфликты при первом `git merge`.
* **Что узнал:** Как работают базовые типы данных, арифметика строк (сумма цифр, реверс). Освоил концепцию словарей (`Dictionary`) на примере подсчета слов и научился считать возраст по дате рождения.

### Уровень 2: ООП, обобщения, паттерны и продвинутый Git (Задания 16–35)
* **Что было сложно:** Реализовать интерфейсы `IComparable` и `IComparer<T>` для правильной сортировки сложных объектов. Понять паттерн «Стратегия» и переопределить `Equals`/`GetHashCode` без ошибок. 
* **Что узнал:** Как писать методы расширения. Зачем нужен `StringBuilder` и `TryParse` (на практике оценил разницу в производительности). Освоил основы LINQ (`GroupBy`, фильтрация, агрегация), `IDisposable`, создание кастомных исключений. Настроил `.editorconfig` и изучил `Conventional Commits` + `rebase`.

### Уровень 3: Производительность, асинхронность и сложный Git (Задания 36–50)
* **Что было сложно:** Понять нюансы работы памяти при выборе между `List<T>` и `LinkedList<T>`. Разобраться, как работает `yield return` (отложенное выполнение) и не блокировать потоки при `async/await`.
* **Что узнал:** Как работает мемоизация и зачем нужны `HashSet` для поиска дубликатов. Научился использовать `Task.WhenAll` для параллельного запуска задач и `CancellationToken` для их безопасной отмены. В Git освоил работу с `stash`, интерактивный `rebase -i`, теги, `reflog` и `bisect`.
